# 个人网页素材说明

本目录用于存放头像和项目封面图，直接替换同名文件即可更新网页内容。

## 文件说明

### 头像
- `avatar.jpg` — 个人头像，建议尺寸 360×360px（正方形），会自动裁切为圆形
  - 占位状态下显示荧光绿渐变背景 + "加糖"标签
  - 放入图片后会自动覆盖占位背景

### 项目封面（如后续扩展为图文卡片）
- `projects/` — 项目封面图目录，建议 16:9 或 4:3 比例

## 替换方式

1. 直接覆盖同名文件（如把你的头像命名为 `avatar.jpg` 替换掉占位文件）
2. 刷新浏览器即可看到更新

## 修改文字内容

如需修改姓名、简介、项目信息等文字内容，编辑 `index.html` 即可：
- 个人简介：搜索 `bio-name` 和 `bio-desc`
- 项目列表：搜索 `project-list`，每个 `<li>` 是一个项目
- 联系邮箱：搜索 `cta-email` 和 `mailto:`

## 修改配色

如需调整配色，编辑 `css/style.css` 顶部的 `:root` 变量：
- `--color-accent`：荧光绿点缀色（当前 #c5ff3d）
- `--color-bg-start/mid/end`：背景渐变色
- `--color-text-primary`：主文字色
